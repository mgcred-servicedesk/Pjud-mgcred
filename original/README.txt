JURÍDICO MG CRED — PROTÓTIPO PARA PUBLICAÇÃO

Este pacote é um site estático e pode ser publicado em qualquer hospedagem que aceite HTML.
Arquivo inicial: index.html

PUBLICAÇÃO MAIS SIMPLES
1. Extraia o ZIP.
2. Envie a pasta/arquivo index.html para um serviço de hospedagem de site estático.
3. O serviço fornecerá um endereço público HTTPS para compartilhamento.

IMPORTANTE
- Esta versão é um PROTÓTIPO DEMONSTRATIVO: os dados exibidos são fictícios/exemplificativos.
- O formulário “Nova solicitação jurídica” ainda não grava dados em servidor.
- Não publique dados reais, processos, documentos, dados pessoais ou informações confidenciais nesta versão.
- Para uso real pela MG Cred, a próxima versão deverá ter autenticação, perfis/permissões, banco de dados, logs, backup e controles adequados de segurança/LGPD.
